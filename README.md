# Saturn Technologies website

Static pages generated by `scripts/build.js` (no dependencies) plus one serverless function, `api/contact.js`, for the enquiry form.
The previous single-file site is preserved in `legacy/index.single-file.html` and in git history.

## Deploy on Vercel
1. Upload/push this folder to your Vercel project (Framework preset: **Other**). `vercel.json` already sets the build command (`node scripts/build.js`) and output folder (`public`).
2. In **Project > Settings > Environment Variables** add (these are secrets, never put them in files):
   - `RESEND_API_KEY`: API key from resend.com
   - `CONTACT_TO_EMAIL`: the inbox that should receive enquiries
   - `CONTACT_FROM_EMAIL`: sender on a domain verified in Resend, e.g. `Saturn Website <enquiries@yourdomain.com>`
3. Redeploy. Until these exist the form tells visitors it is unavailable. It never pretends to send.

## Editing content (no coding needed)
| What | File |
|---|---|
| Phone, email, WhatsApp, address, CIN, GSTIN, social links, site URL, legal switches | `site.config.json` (anything left empty is hidden on the site) |
| Hosting specs and prices | `content/hosting.json` (replace `null` with a value only after you have verified it) |
| Services, FAQs, demo/client projects, testimonials, training programme | `content/*.json` |
After editing run `npm run build` (Vercel does this automatically on deploy). `ADMIN-CHECKLIST.md` is regenerated each build and lists what is still missing.

## Commands
`npm run build` build to `public/` · `npm run dev` build and serve on :3000 (with the API) · `npm test` build and run the 459-check test-suite.
